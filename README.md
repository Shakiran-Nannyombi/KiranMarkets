# Kiran Markets — AI B2B Marketing Strategy Platform & Nova Strategist

**Kiran Markets** is an executive-level B2B strategic marketing web application powered by **Nova**, an AI Marketing Specialist powered by Google Gemini.

The platform provides an interactive discovery experience that audits prospective client growth bottlenecks in real time, generates tailored marketing hooks, calculates projected B2B growth ROI, and seamlessly connects qualified leads to strategy calls with founder Kiran.

---

## 🚀 Key Features

- **Nova AI Strategy Engine**: Interactive 5-stage discovery session that asks targeted questions, synthesizes business bottlenecks, and outputs high-impact strategic campaign hooks.
- **Real-Time Gemini Integration**: Server-side proxy API (`/api/nova` and `/api/nova/chat`) utilizing the `@google/genai` SDK with Gemini 3.6 Flash.
- **Custom Brand Identity**: Integrated visual logo, "Professional Polish" high-contrast theme, and executive typography.
- **Interactive B2B Growth ROI Calculator**: Real-time slider-based economic modeling for pipeline velocity, lead cost reduction, and ARR targets.
- **Consultation Scheduling Modal**: Pre-fills discovery briefs generated by Nova for deep-dive calls with founder Kiran.
- **Vercel Ready**: Built-in Vercel serverless functions configuration (`vercel.json` + `/api/index.ts`).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend**: Node.js, Express, `@google/genai` TypeScript SDK
- **AI Model**: Google Gemini 3.6 Flash (`gemini-3.6-flash`)
- **Deployment**: Compatible with Cloud Run containers and Vercel Serverless Functions

## ⚡ Quick Start (Local Development)

### 1. Prerequisites
Ensure you have **Node.js 18+** installed.

### 2. Configure Environment Variables
Create a `.env` file in the project root (or set your environment variables):

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Install Dependencies & Run Server
```bash
# Install packages
npm install

# Run dev server
npm run dev
```

Open `http://localhost:3000` in your browser.

---

## 🌐 Deploying to Vercel

This repository is pre-configured for one-click deployment to **Vercel**:

1. **Push your code** to GitHub or GitLab.
2. **Import Project into Vercel**:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. **Environment Variables**:
   - Add `GEMINI_API_KEY` under **Project Settings -> Environment Variables**.
4. **Deploy**: Vercel will automatically build the static assets and deploy the backend Express API via `/api/index.ts`.
